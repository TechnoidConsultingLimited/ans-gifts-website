# ANS Gifts — Premium London Souvenir Storefront

A flagship e-commerce experience for **ANS Gifts** (ansgifts.co.uk) — a London-based wholesaler and retailer of authentic British souvenirs.

## ✨ Live Demo

👉 **[View the live site →](https://techonidconsultinglimited.github.io/ans-gifts-website/)**

## 🎯 Project Brief

The client had an existing WordPress site but wanted a premium, world-class redesign with:

- Editorial, luxury British aesthetic
- AI-powered shopping concierge
- Full wholesale / trade experience
- Mobile-first responsive layout
- Fast, self-contained, zero-dependency build

## 🧩 Features

| Feature | Description |
|---|---|
| **Custom classic crest logo** | Hand-built SVG with crown, monogram & wordmark |
| **AI Concierge** | Natural-language product search + wholesale FAQ |
| **Live product filtering** | Category chips + search with instant results |
| **Working cart** | Add / remove / adjust qty, persists via `localStorage` |
| **Quick view modal** | Product detail overlay with trade pricing |
| **Wishlist** | Heart-toggle saving, persistent |
| **Trade login modal** | Wholesale account sign-in flow |
| **Contact & newsletter forms** | Validated, with toast confirmations |
| **Scroll progress + reveals** | Editorial motion system |
| **Fully responsive** | 320px → widescreen |

## 🛠 Tech Stack

- **Pure HTML, CSS, JavaScript** — zero build step, zero dependencies
- **Google Fonts** — Fraunces (display) + Inter (body)
- **LocalStorage** for cart, wishlist and trade session
- **Vanilla SVG** for the logo and iconography
